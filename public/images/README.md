# Your Photos

Place your driftwood art and wedding creation photos in this folder.

To use them on the site, use the path: `/images/your-photo-name.jpg`

### Suggested Naming:
- `hero-best-piece.jpg` (For the home page)
- `mirror-1.jpg`, `mirror-2.jpg` (For store items)
- `wedding-arch.jpg` (For the wedding page)
